## 🤖 Overview

Weesper Neon Flow displays live transcription captions as a glowing neon overlay on your screen, perfect for streamers, presentations, and accessibility use cases.

Whether you're a newcomer or a veteran, Weesper Neon Flow provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Neon Overlay** | Stylish neon-glow captions rendered on top of any application |
| **Real-Time** | Sub-second transcription latency using local Whisper inference |
| **Custom Colors** | Fully customisable glow colors, font, and text size |
| **Stream Ready** | Window-capture friendly for OBS and streaming software |
